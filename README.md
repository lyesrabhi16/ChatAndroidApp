# Chat_mobileApp

importer chatdb.sql dans phpmyadmin.\n
avec un terminal (ou cmd...) aller au dossier du projet ( ou il ya le dossier app server.js package.json...)\n
et executer ces commande:
    npm install (elle sert a installé les dependeces du serveur)\n
    npm run server (elle démarre  le serveur)\n
apres sa dans android studio il faut configuré votre ip dans la classe Configs (Attribut IP)\n
