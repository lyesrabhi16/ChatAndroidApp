# Chat_mobileApp

## Base des donnes
importer chatdb.sql dans phpmyadmin.

## Serveur
avec un terminal (ou cmd...) aller au dossier du projet ( ou il ya le dossier app server.js package.json...)  
et executer ces commande:  
    ```
    npm install
    ```  
    > sert a installé les dependeces du serveur  
    ```
    npm run server 
    ```  
    > démarre  le serveur

## Java/AndroidStudio 
apres sa dans android studio il faut configuré votre ip dans la classe Configs 
    > Attribut IP
